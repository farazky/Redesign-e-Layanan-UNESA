# Redesign-e-Layanan-UNESA
Proyek ini merupakan hasil evaluasi usability dan redesign antarmuka e-Layanan UNESA pada fitur pengaduan. Berdasarkan hasil kuesioner dan wawancara, ditemukan beberapa permasalahan seperti tampilan yang kurang menarik, navigasi yang membingungkan, serta alur pengaduan yang kurang jelas. Oleh karena itu, dilakukan perancangan ulang dengan pendekatan User-Centered Design (UCD) untuk meningkatkan kemudahan penggunaan, kenyamanan, dan pengalaman pengguna.

# Fitur Utama
- Login pengguna
- Melihat seluruh pengaduan
- Pengajuan pengaduan
- Upload bukti foto atau dokumen pengaduan
- Pemantauan status pengaduan
- Pusat bantuan
- Panduan penggunaan
- Alur penanganan laporan
- FAQ
- Popup konfirmasi logout
- Prototype interaktif berbasis Figma
